# 📚 BibliteCuario

Repositorio desarrollado como evidencia para el programa **Análisis y Desarrollo de Software (ADSO)**. Este proyecto implementa una aplicación estructurada bajo buenas prácticas de programación, control de versiones con **Git bash** y navegación interactiva por menús.

---

## 🚀 Características de la Aplicación

El sistema cumple con los siguientes requerimientos funcionales y de experiencia de usuario:
* **Navegación Completa:** Permite navegar desde el menú principal hacia todos los submenús correspondientes.
* **Control de Retorno:** Opción funcional para volver al menú anterior en cada sección.
* **Confirmación de Acciones:** Mensajes de confirmación para procesos críticos como el reinicio del sistema o la salida de la aplicación.
* **Validación de Entradas:** Control de errores ante opciones inválidas, solicitando nuevamente el ingreso de los datos sin interrumpir la ejecución.

---

## 🌳 Estructura de Ramas (Git flow)

Este proyecto implementa el flujo de trabajo de Git flow.
* `main`: Rama principal que contiene las versiones estables y listas para producción.
* `develop`: Rama de integración para el desarrollo continuo de las funcionalidades.
* `feature/*`: Ramas temporales creadas para el desenvolvimento de módulos específicos, las cuales fueron debidamente fusionadas a `develop.
